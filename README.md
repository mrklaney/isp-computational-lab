# ISP Computational Lab

Runnable examples built while studying Jacob Barandes's indivisible stochastic processes (ISP) papers.

- [Notebook 06: Division events](https://mrklaney.github.io/isp-computational-lab/06_division_events.html). Rebuilds Paper 1, §3.7 by simulation: a qubit is recorded by a fresh environment qubit every δt, and the process moves from indivisible oscillation through Markov relaxation to Zeno freezing.
